# Tokens

- `tokens.json`: every value, for both modes (`modes.dark`, `modes.light`), both materials, plus type, space, radius, motion and the derivation rules.
- `omarchy-themes-resolved.json`: each of the 23 Omarchy themes (branch `quattro`, 2026-11-13) resolved by the rules in `docs/03-theming.md`: mode, accent, ink, contrast, tags. Use it as the test fixture for theme resolution.
