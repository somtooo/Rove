The rules
What starts a search
Any printable character, while the window has focus and no text field or menu has it. Default, Mac and Windows presets only. The Vim preset keeps letters as commands and uses / to search, as Vim does.
What starts path entry
“/” or “~” as the first character, or Ctrl+L. Esc returns to the title.
Folder vs everywhere
Typing filters the current folder (instant, filter). Tab or ↓ past the last match switches to all subfolders (search, streamed and ranked). The scope chip shows which one you are in.
Keys while searching
↑ ↓ ← → move among matches; Enter opens; Space previews; Ctrl+Enter opens in a new tab; Backspace on empty text closes the search.
Leaving
Esc clears and restores the previous selection and scroll. Navigating elsewhere clears it too. The search never persists across folders.
Special syntax
tag:red, kind:image, >10mb, modified:today. Shown as suggestions once you type “:”.
